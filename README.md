# Pink Heart Animation 💖✨

> Animação interativa de coração pulsante com efeitos de partículas e estética neon em HTML5 Canvas e CSS3.

[![Canvas](https://img.shields.io/badge/HTML5-Canvas-E34F26.svg)](#)
[![JavaScript](https://img.shields.io/badge/JavaScript-ES6-F7DF1E.svg)](#)

---

## 📖 Descrição

Demonstração visual desenvolvida com equações paramétricas para desenho de curvas cardíacas matemáticas em um elemento `<canvas>`, renderizando centenas de partículas cintilantes que reagem ao mouse e pulsam sincronizadamente.
